Lobby am Smartboard

Öffne die Lobby auf dem Rechner am Smartboard. Die Klasse kommt mit dem Handy per QR-Code oder Code hinein, bietet Spiele an oder steigt bei einem Angebot ein. Am Smartboard sieht jeder, was gerade los ist.

Mit Code beitreten

Für das Handy: Code von der Smartboard-Lobby eingeben.

Wie heißt du im Spiel?

Ein Spitzname reicht. Er wird nur in der Lobby angezeigt und nirgends gespeichert.
